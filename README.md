# PrimeNest Properties

Production-ready Next.js prototype built with **Next.js 16.3.6**, App Router, Tailwind CSS v4, shadcn/ui-style components, Lucide React and Framer Motion.

## Run locally

```bash
npm i
npm run dev
```

## Production

```bash
npm run build
npm start
```

Deploy directly to Vercel. No backend or environment variables are required for the demo. Replace WhatsApp number, map URL, copy and imagery before launch.

## Images
Photography is loaded from real Unsplash CDN URLs and credited to Unsplash in the site footer.

## Structure
- `app/` — App Router pages
- `components/ui/` — reusable shadcn/ui-style Button component
- `data/` — hardcoded site content
- `public/` — static public assets
